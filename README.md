# Poshan Scheme Coverage & Infrastructure Analysis

## Project Overview
This project analyzes the coverage, infrastructure, and beneficiary statistics of the Poshan Scheme using Power BI.

## Tools Used
- Power BI
- Excel / CSV
- DAX
- Power Query

## Features
- KPI Cards
- Interactive Dashboard
- Interactive Navigation Buttons
- Table & Visual Toggle View
- State-wise Analysis
- Beneficiary Insights

## Files Included
- Power BI Dashboard (.pbix)
- Cleaned Dataset
- Documentation Report
- Dashboard Screenshot
